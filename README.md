# LiveWallpaper

Видеообои для Android 12 и новее. При включении экрана выбранный MP4 проигрывается один раз без звука. Последний кадр остаётся видимым до выключения экрана. При следующем пробуждении видео запускается с начала.

Video wallpaper for Android 12 and later. When the screen is turned on, the selected MP4 is played once without sound. The last frame remains visible until the screen is turned off. The next time the screen is awakened, the video starts from the beginning.
## Установка обоев

1. Установите APK и откройте приложение «Видеообои».
2. Нажмите «Выбрать MP4» и укажите файл. Приложение сохранит свою копию, поэтому исходный файл можно переместить или удалить.
3. Нажмите «Установить обои». В системном предпросмотре выберите нужный экран и подтвердите установку.

Приложение можно закрыть. Android запускает воспроизведение, когда обои видны и экран активен. При скрытии обоев или выключении экрана декодер освобождается. Чтобы обновить уже установленные обои, нажмите «Заменить видео».

## Совместимость

Требуется устройство с поддержкой живых обоев. Возможность выбрать только экран блокировки зависит от прошивки и системного установщика. На Samsung Galaxy S21 FE с Android 16 и One UI 8.0 в диалоге доступен отдельный пункт «Заблокированный экран». [Документация Android](https://developer.android.com/reference/android/app/WallpaperManager#ACTION_CHANGE_LIVE_WALLPAPER)

## Сборка

Откройте проект в Android Studio с JDK 17, Android SDK Platform 36 и Build Tools 35.0.0. Из корня проекта выполните команду для своей системы.

| Система | Команда |
| --- | --- |
| Windows (PowerShell) | `.\gradlew.bat assembleDebug` |
| Linux / macOS | `./gradlew assembleDebug` |

Готовый APK находится в `app/build/outputs/apk/debug/app-debug.apk`.

## Как удерживается последний кадр

Интерфейс написан на Kotlin и Jetpack Compose. Каждый `WallpaperService.Engine` управляет своим Media3 ExoPlayer. По окончании ролика приложение копирует последний выведенный кадр с поверхности плеера и рисует его как неподвижное изображение. Если Android пересоздаёт поверхность, приложение выводит сохранённое изображение повторно. При следующем пробуждении управление снова получает видеоплеер.

Инструментальные тесты используют H.264-ролик, в котором только последний кадр белый. На Galaxy S21 FE тесты подтвердили цвет кадра после окончания ролика, замены поверхности и перерисовки. На эмуляторе Android 16 проверены установка на экран блокировки и два последовательных пробуждения.

Для запуска тестов подключите устройство или запустите эмулятор, затем выполните `./gradlew connectedDebugAndroidTest` (в PowerShell — `.\gradlew.bat connectedDebugAndroidTest`).
